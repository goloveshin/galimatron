# Dictionary

## Version 0

- `group_name`
- `published`
- `struct_name`: the C++ type of an aggregate
- `uuid`: stable id of a message
- `version_namespace`
- `version_number`

## Version 1

- `message`: text carried by a system message
- `system_message`

## Version 2

- `lit`
- `payload_message`: a user message, not a system message

## Version 3

- `candela`
- `metres`

## Version 4

- `bearing`
- `calm`
- `enum_name`: the C++ enumeration type
- `kind`
- `sail`
- `sea`
- `steamer`
- `swell`

## Version 5

- `day`
- `fog`
- `gale`
- `lamp`
- `launch`
- `name`: a string the watch uses for a vessel

## Version 6

- `greeting`: North Light on watch
